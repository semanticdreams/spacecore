# 2026-10-28

[Workflow-backed agent sessions](/dev/features/workflow-backed-agent-sessions) expose live OpenCode sessions — sessions, messages and message parts — as first-class graph topology, so [the graph app](/dev/features/opencode-agent-workflow) can inspect real running agent state instead of inferred summaries, with capability wiring aligned to the exact long-term branches. Native [SELinux-aware record publication](/dev/features/record-publication-selinux) adds bounded, read-only label validation without relabeling or certification, while [VirtualInput](/dev/features/lazy-text-buffer-virtual-input) opens full composed text in an external editor and rejects stale completions. [Development records](/dev/development-records) become tracked, browsable, cross-linked documentation: specs and plans indexes are generated automatically, record navigation is enforced in CI, and durable progress stays out of ignored scratch directories — grounding [the live-dev workflow](/dev/features/live-dev) in reviewable history rather than ephemeral session dumps.
